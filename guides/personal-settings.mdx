## 个人设置

### 主题

支持浅色 / 深色 / 跟随系统三种模式。

### 语言

界面语言支持中文、English、ภาษาไทย。

### 通知偏好

配置接收通知的渠道和频率：

- 任务完成通知
- 失败告警通知
- 团队共享通知

## 团队设置

### 成员管理

- 邀请新成员加入团队
- 设置成员角色（管理员 / 普通成员 / 只读）
- 查看成员的助手和技能使用情况

### 配额管理

| 配置项 | 说明 |
| :--- | :--- |
| 每日 Token 上限 | 团队每日可消耗的最大 Token 数 |
| 单任务 Token 上限 | 单次任务执行的 Token 上限 |
| 并发任务数 | 同时运行的最大任务数 |

### 模型路由

见 [模型路由配置](/guides/model-routing)。

## 重试策略

当定时任务执行失败时，AgentZ 支持以下重试策略：

| 策略 | 说明 |
| :--- | :--- |
| `skip` | 跳过本次，等待下次计划执行 |
| `retry` | 按配置重试（最多 N 次，间隔递增） |
| `alert` | 不重试，直接通知管理员 |
| `retry_then_alert` | 重试耗尽后通知管理员（默认） |

## 配置示例

```json
{
  "retryPolicy": {
    "maxRetries": 3,
    "backoff": "exponential",
    "initialDelay": 60,
    "alertAfterFailure": true,
    "alertTarget": ["管理员", "#运维告警群"]
  }
}
```

## 失败原因排查

常见失败原因：

- **MCP 连接超时**：外部系统不可用，检查网络和服务状态
- **权限不足**：Token 过期或权限被收回，需重新配置凭证
- **输入数据异常**：上游数据格式变化，需更新助手的工作指令
- **执行超时**：任务耗时超过上限，考虑拆分为多个子任务

在「Agent Space → 运行历史」中可以查看每次执行的详细日志。

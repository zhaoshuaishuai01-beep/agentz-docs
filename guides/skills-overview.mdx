## 什么是技能

技能是助手的原子能力单元。每个技能封装一种特定能力——读写文件、调用 API、执行计算、生成报告等。

## 技能分类

| 类型 | 说明 | 示例 |
| :--- | :--- | :--- |
| 内置技能 | AgentZ 预置的通用能力 | `xlsx`、`pptx`、`pdf`、`browser` |
| 社区技能 | 社区贡献的开源技能 | `dingtalk-notifier`、`data-crawler` |
| 自建技能 | 企业自行开发的私有技能 | `internal-erp`、`custom-report` |

## 技能的组合

一个助手可以同时挂载多个技能。执行任务时，助手会根据工作指令自动判断调用哪些技能、以什么顺序调用。

```
助手：出库数据分析师
├── xlsx（读取 ERP 导出的 Excel）
├── pptx（生成汇报 PPT）
└── dingtalk-notifier（推送到钉钉群）
```

## 技能的生命周期

技能支持版本管理。更新技能不会影响正在执行的任务，下次执行时自动使用最新版本。

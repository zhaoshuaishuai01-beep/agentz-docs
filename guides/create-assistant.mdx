## 创建流程

AgentZ 提供四步向导帮助你快速创建助手：

### 第一步：基础信息

填写助手的名称、头像和描述。这些信息会成为助手的「身份」——影响它的自我定位和行为风格。

| 字段 | 说明 | 建议 |
| :--- | :--- | :--- |
| 名称 | 助手的显示名称 | 用岗位名或职能命名，如「出库分析师」 |
| 头像 | 视觉标识 | 选择与职能相关的图标 |
| 描述 | 一句话说明助手的职责 | 包含核心任务和输出物 |

### 第二步：配置 Prompt

使用三段式结构编写 Prompt，详见 [配置 Prompt](/guides/configure-prompt)。

### 第三步：挂载技能

从技能库中选择助手需要的能力。技能可以随时增减。

### 第四步：设置触发方式

选择手动触发、定时执行、或事件驱动。

## 保存为模板

创建完成后，你可以将助手配置保存为模板，方便团队其他成员快速复制使用。

点击助手设置页右上角「保存为模板」即可。

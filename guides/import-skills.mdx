## 导入方式

AgentZ 支持两种技能导入方式：

### 方式一：Git URL 导入

适合持续维护的技能，支持自动同步更新。

```bash
# 在「技能管理」页面填入 Git 仓库地址
https://github.com/your-org/skill-name.git
```

系统会自动拉取仓库内容，解析 `skill.yaml` 并注册技能。当仓库有更新时，AgentZ 会自动同步最新版本。

### 方式二：ZIP 包上传

适合一次性导入或无 Git 环境的场景。

1. 将技能目录打包为 `.zip` 文件
2. 在「技能管理」页面点击「上传 ZIP」
3. 系统自动解析并注册

## 管理操作

- **启用/禁用**：临时关闭某个技能而不删除它
- **版本回滚**：Git 导入的技能支持回滚到历史版本
- **依赖检查**：查看哪些助手正在使用该技能
- **删除**：彻底移除技能（需先解除所有助手的挂载）

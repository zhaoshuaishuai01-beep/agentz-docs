## Agent Space 概览

Agent Space 是 AgentZ 的运行监控中心，提供所有助手的执行状态一览。

## 监控面板

### 运行状态

- **运行中**：当前正在执行的任务，可实时查看进度
- **排队中**：等待资源的任务
- **已完成**：成功执行的历史任务
- **失败**：执行出错的任务，附带错误详情

### 关键指标

| 指标 | 说明 |
| :--- | :--- |
| 成功率 | 过去 7 天的任务成功率 |
| 平均耗时 | 任务从触发到完成的平均时长 |
| 活跃助手数 | 有定时任务在运行的助手数量 |
| Token 消耗 | 各助手的模型调用量 |

## 运行历史

点击任意一条历史记录可以查看：

- 完整的执行日志（每一步的输入、输出、耗时）
- 调用的技能和 MCP 工具列表
- 最终输出物（文件、消息等）
- 错误堆栈（如果失败）

## 权限模型

AgentZ 对 MCP 工具实行**最小权限原则**：助手只能访问被明确授权的工具和操作。

## 权限维度

| 维度 | 说明 |
| :--- | :--- |
| 工具级别 | 哪些助手可以使用该 MCP 工具 |
| 操作级别 | 允许执行哪些具体操作（读/写/删除） |
| 数据范围 | 可访问的数据边界（如只能查询本部门数据） |

## 配置方式

在「设置 → MCP 工具 → 权限」中，为每个 MCP 连接设置：

1. **可用角色**：哪些团队角色的助手可以调用
2. **允许操作**：勾选允许的操作类型
3. **数据过滤**：配置数据访问范围表达式

## 审计

所有 MCP 调用会记录在审计日志中，包括调用时间、调用者、操作内容和返回状态。管理员可在「Agent Space → 审计日志」中查看。

## 审计范围

AgentZ 记录以下所有操作的审计日志：

- 助手的每次执行（触发方式、输入参数、输出结果）
- MCP 工具的每次调用（操作类型、数据范围、返回状态）
- 配置变更（Prompt 修改、技能增减、权限调整）
- 用户操作（登录、共享、删除等）

## 日志字段

每条审计记录包含：

| 字段 | 说明 |
| :--- | :--- |
| 时间 | 精确到毫秒的操作时间 |
| 操作者 | 执行操作的用户或助手 |
| 操作类型 | create / read / update / delete / execute |
| 目标对象 | 被操作的资源名称和 ID |
| 详情 | 操作的具体内容摘要 |
| 状态 | 成功 / 失败 / 部分成功 |

## 查询与导出

- 支持按时间范围、操作者、操作类型等多维度筛选
- 支持导出为 CSV 用于外部审计系统对接
- 日志保留期限可在团队设置中配置（默认 90 天）

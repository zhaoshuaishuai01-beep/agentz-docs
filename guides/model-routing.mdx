## 什么是模型路由

模型路由让你为不同类型的任务分配不同的大语言模型，在成本、速度和质量之间取得最佳平衡。

## 路由策略

| 策略 | 适用场景 | 示例模型 |
| :--- | :--- | :--- |
| 高质量优先 | 复杂推理、长文生成 | GPT-4o / Claude 3.5 |
| 低延迟优先 | 简单分类、快速响应 | GPT-4o-mini / Qwen-Turbo |
| 低成本优先 | 批量处理、容错性高的任务 | Qwen-Plus / DeepSeek |
| 自动选择 | 系统根据任务复杂度自动分配 | — |

## 配置方式

在「设置 → 模型路由」中：

1. 设置默认模型（所有助手的兜底选择）
2. 为特定助手指定专用模型
3. 配置 fallback 链（主模型不可用时的备选）

```json
{
  "default": "qwen-plus",
  "rules": [
    {
      "assistant": "出库数据分析师",
      "model": "gpt-4o",
      "fallback": ["claude-3.5-sonnet", "qwen-max"]
    }
  ]
}
```

## 成本控制

结合配额管理和模型路由，你可以实现：

- 高价值任务用高质量模型，保证输出品质
- 日常任务用经济模型，控制整体成本
- 设置 Token 上限，防止异常任务消耗过多资源

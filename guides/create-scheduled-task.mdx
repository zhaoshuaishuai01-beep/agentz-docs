## 什么是定时任务

定时任务让助手在指定时间自动触发执行，无需人工干预。适合日报生成、数据同步、定时巡检等场景。

## 创建步骤

1. 打开目标助手的设置页
2. 切换到「定时任务」标签
3. 点击「新建任务」

### 配置项

```json
{
  "cron": "0 8 * * *",
  "description": "每日 08:00 生成出库日报",
  "input": {
    "date": "yesterday"
  },
  "notify": ["张三", "#仓储运营群"]
}
```

### Cron 表达式常用示例

| 表达式 | 含义 |
| :--- | :--- |
| `0 8 * * *` | 每天 08:00 |
| `0 8 * * 1-5` | 工作日 08:00 |
| `0 */2 * * *` | 每 2 小时 |
| `0 9 * * 1` | 每周一 09:00 |
| `0 9 1 * *` | 每月 1 号 09:00 |

## 执行结果

任务执行完成后，结果会：

- 保存在「Agent Space → 运行历史」中
- 按配置推送到指定接收人或群
- 如果执行失败，触发重试策略或告警

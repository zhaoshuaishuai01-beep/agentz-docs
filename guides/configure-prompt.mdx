## 三段式 Prompt 结构

AgentZ 推荐使用 **[角色定义] + [工作指令] + [用户上下文]** 的三段式结构来配置助手的 Prompt。

### 角色定义

告诉助手「你是谁」。明确的身份定义会让助手的输出更加专业和一致。

```text
[角色定义]
你是一位资深供应链数据分析师，擅长从多系统数据中提取业务洞察，
表达风格简洁直接，偏好用数据说话。
```

### 工作指令

告诉助手「做什么、怎么做」。用编号列表写清楚执行步骤和输出要求。

```text
[工作指令]
1. 每日从 ERP 拉取前一天的出库明细
2. 按品类维度汇总件数和金额
3. 计算环比变化，标记异常波动（±20%）
4. 生成 Excel 明细 + PPT 摘要，推送到指定群
```

### 用户上下文

告诉助手「在什么场景下工作」。提供部门、关注范围、汇报对象等背景信息。

```text
[用户上下文]
所属部门：华东仓储中心
关注品类：食品、日化、母婴
汇报对象：运营总监 张三
输出语言：中文
```

## 最佳实践

<Tip>
**指令越具体，助手越靠谱。** 避免模糊表述如「分析一下数据」，改为「按品类维度汇总件数和金额，计算环比」。
</Tip>

- 角色定义控制在 2-3 句话，点明专业领域和沟通风格
- 工作指令用编号列表，每步一个明确动作
- 用户上下文提供助手无法自动获取的业务背景
- 避免在 Prompt 中硬编码会变化的数据（如日期），交给定时任务参数传入

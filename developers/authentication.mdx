## 获取 API Key

1. 登录 AgentZ 控制台
2. 进入「设置 → API 密钥」
3. 点击「生成新密钥」
4. 复制并妥善保存（密钥只显示一次）

<Warning>
API Key 拥有你账户的完整权限，请勿在客户端代码或公开仓库中暴露。
</Warning>

## 使用方式

在每个 HTTP 请求的 Header 中携带：

```
Authorization: Bearer YOUR_API_KEY
```

### cURL 示例

```bash
curl -X GET https://api.agentz.dev/v1/assistants \
  -H "Authorization: Bearer azk_live_xxxxxxxxxxxxxxxx"
```

### Node.js 示例

```javascript
const response = await fetch('https://api.agentz.dev/v1/assistants', {
  headers: {
    'Authorization': 'Bearer azk_live_xxxxxxxxxxxxxxxx'
  }
});
```

## Key 管理

- 每个账户最多创建 5 个 API Key
- 可以为每个 Key 设置独立的权限范围
- 支持随时吊销（吊销后立即失效）
- 建议定期轮换 Key（90 天）

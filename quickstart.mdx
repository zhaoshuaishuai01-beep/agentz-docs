这本手册帮你 **5 分钟创建第一个助手**，30 分钟把团队第一个例行报表交给 AgentZ。

## Step 1 — 创建助手

点击左侧「+ 新建助手」，填写基础信息：

| 字段 | 示例 |
| :--- | :--- |
| 名称 | 出库数据分析师 |
| 头像 | 选一个图标或上传自定义头像 |
| 描述 | 每日自动汇总出库数据，生成趋势分析报告 |

<Tip>
名称和描述会影响助手的自我认知，写得越清晰，助手表现越好。
</Tip>

## Step 2 — 配置三段式 Prompt

AgentZ 使用 **[角色定义] + [工作指令] + [用户上下文]** 的三段式 Prompt 结构：

```text
[角色定义]
你是一位仓储数据分析专家，擅长从 ERP 出库明细中提取关键指标。

[工作指令]
1. 每日 8:00 从 ERP 拉取前一天出库数据
2. 按品类汇总件数、金额，计算环比变化
3. 异常波动（环比 ±20%）标红并给出可能原因
4. 输出 Excel + 一页 PPT 摘要

[用户上下文]
所属部门：华东仓储中心
关注品类：食品、日化、母婴
汇报对象：运营总监 张三
```

## Step 3 — 挂载技能

在「技能」面板勾选助手需要的能力：

- `xlsx` — 读写 Excel 文件
- `pptx` — 生成演示文稿
- `internal-erp` — 连接内部 ERP 系统（需先配置 MCP）

<Info>
技能可以随时增减，不会影响已生成的历史结果。
</Info>

## Step 4 — 配置定时任务

切换到「定时任务」标签，设置执行计划：

```json
{
  "cron": "0 8 * * *",
  "description": "每日 08:00 自动拉取出库数据并生成报告",
  "notify": ["张三", "#仓储运营群"]
}
```

保存后，助手会在指定时间自动执行并推送结果。

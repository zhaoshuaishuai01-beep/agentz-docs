title: "核心概念"
description: "理解 AgentZ 的四个核心组件：助手、技能、MCP 工具、定时任务"
---

AgentZ 的架构围绕四个核心概念构建，理解它们之间的关系是高效使用产品的关键。

## 助手 (Assistant)

助手是 AgentZ 的核心执行单元。每个助手有独立的身份（Prompt）、技能集合和执行上下文。

你可以把助手想象成一个「虚拟岗位」——它知道自己是谁、能做什么、该向谁汇报。

```
助手 = 角色定义 + 工作指令 + 技能集合 + 触发方式
```

## 技能 (Skill)

技能是助手的**原子能力单元**。每个技能封装一种特定能力，例如读写 Excel、生成 PPT、调用某个 API。

技能的特点：

- **可复用**：同一个技能可以被多个助手挂载
- **可组合**：助手可同时挂载多个技能，按需调用
- **可自建**：通过 `skill.yaml` + 入口脚本即可定义新技能

## MCP 工具 (MCP Tool)

MCP（Model Context Protocol）是 AgentZ 连接外部系统的**协议层**。通过 MCP，助手可以操作 ERP、CRM、钉钉、数据库等任意外部服务。

支持三种连接方式：

| 类型 | 适用场景 |
| :--- | :--- |
| STDIO | 本地命令行工具 |
| HTTP | RESTful API 服务 |
| SSE | 需要实时推送的服务 |

<Note>
MCP 工具需要管理员配置连接凭证和权限范围，普通用户只能使用已授权的工具。
</Note>

## 定时任务 (Scheduled Task)

定时任务让助手**按计划自动执行**，无需人工触发。支持 Cron 表达式定义执行频率。

典型场景：每日晨报、周报自动生成、定时数据同步、超时订单告警。

## 它们之间的关系

```
┌─────────────────────────────────────┐
│            定时任务 (触发)            │
│         cron / 手动 / 事件           │
└──────────────┬──────────────────────┘
               ▼
┌─────────────────────────────────────┐
│         助手 (编排 & 执行)           │
│    角色定义 + 工作指令 + 上下文       │
└──────┬──────────────────┬───────────┘
       ▼                  ▼
┌─────────────┐    ┌─────────────┐
│  技能 (能力) │    │ MCP (连接)   │
│ xlsx / pptx │    │ ERP / CRM   │
└─────────────┘    └─────────────┘
```

理解了这四层，你就可以灵活组装出满足各种业务场景的自动化方案了。

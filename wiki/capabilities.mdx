<Note>
  以下六大能力用于官网首页、产品功能页、开发者页、安全页等所有位置的统一表达。
</Note>

## 岗位化 Agent 编排

**一句话说明**：面向岗位创建专属 AI 助手，而不是通用聊天机器人。

**关键子能力**：

- Prompt 模板
- 角色设定
- 权限边界
- 多 Agent 协作

**官网出现位置**：首页核心能力 c1、产品功能页能力 1。

---

## 工具调用 & MCP 生态

**一句话说明**：让 Agent 会「用工具」——调 API、查数据库、发消息、操作系统。

**关键子能力**：

- MCP 协议接入
- 内置工具集市
- 自定义函数
- 代码执行沙箱

**官网出现位置**：首页核心能力 c2、产品功能页能力 2、开发者页。

---

## 知识库 & RAG

**一句话说明**：把企业私有知识变成 Agent 的长期记忆。

**关键子能力**：

- 文档摄入（PDF / DOCX / 网页）
- 向量检索
- 混合检索
- 引用溯源

**官网出现位置**：产品功能页能力 3、使用手册。

---

## 长期记忆 & 上下文

**一句话说明**：让 Agent 记得每一次对话、每一个用户偏好。

**关键子能力**：

- 会话记忆
- 用户画像记忆
- 组织记忆
- 遗忘策略

**官网出现位置**：首页核心能力 c3、产品功能页能力 4。

---

## 自主任务执行（Agentic Workflow）

**一句话说明**：从「回答问题」进化到「完成任务」。

**关键子能力**：

- 任务规划
- 多步执行
- 异常重试
- 人机协同确认

**官网出现位置**：首页核心能力 c4、产品功能页能力 5。

---

## 企业级管控

**一句话说明**：让 IT / 安全 / 合规团队敢用、能管。

**关键子能力**：

- 组织架构对接
- 权限管控
- 审计日志
- 私有化部署
- 模型可切换

**官网出现位置**：产品功能页能力 6、安全页。

<Note>
  以下术语来自 AgentZ 六大核心能力的关键子能力，用于全站统一表达。
</Note>

## Agent（岗位化 Agent）

面向具体业务岗位创建的专属 AI 助手，具备角色设定、权限边界与工具调用能力，而不是通用聊天机器人。

## Agentic Workflow（自主任务执行）

Agent 从「回答问题」进化到「完成任务」的能力，包含任务规划、多步执行、异常重试、人机协同确认。

## MCP（Model Context Protocol）

AgentZ 支持的工具调用协议，让 Agent 可以接入外部 API、数据库、消息系统与操作系统。

## Prompt 模板

岗位化 Agent 编排的关键子能力之一，用于沉淀角色设定、任务描述、输出规范。

## RAG（Retrieval-Augmented Generation）

检索增强生成，把企业私有知识（PDF / DOCX / 网页等）经过向量检索与混合检索后作为上下文，并支持引用溯源。

## 长期记忆

让 Agent 记得每一次对话与用户偏好，包含会话记忆、用户画像记忆、组织记忆与遗忘策略。

## 权限边界

岗位化 Agent 的关键约束项，定义单个 Agent 可访问的数据、工具与操作范围。

## 私有化部署

企业级管控子能力之一，支持将 AgentZ 部署到客户自有环境，并可切换底层模型。

## 审计日志

企业级管控子能力之一，记录 Agent 的对话、工具调用与关键操作，供 IT / 安全 / 合规团队追溯。

## 代码执行沙箱

工具调用的关键子能力，用于安全隔离地运行 Agent 生成或调用的代码。
